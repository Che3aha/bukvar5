BUKVAR — GITHUB UPLOAD

1. Extract this ZIP on your computer. Do not upload the ZIP itself.
2. In your GitHub repository choose Add file > Upload files.
3. Drag index.html, the entire assets folder, and .nojekyll into the upload area. Keep the assets folder intact.
4. Commit changes.
5. For a public website, go to Settings > Pages, choose Deploy from a branch, then main and / (root), and Save.

The HTML uses files from assets; upload both together. The original single-file offline edition is separate.
All animations, narration and video are included. No external media service is required.
Tracking: open the app's parent settings and configure your GoatCounter code. If exporting an updated index.html, keep the same assets folder.
